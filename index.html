P1 · raio-x da linguagem

Afinal, o que é esse tal de PHP?

PHP é a linguagem que trabalha nos bastidores da web. Enquanto o HTML monta a vitrine, o PHP atende o pedido, consulta o banco e devolve a página pronta. E faz isso há mais de 30 anos.

  1. NavegadorVocê pede uma página, por exemplo cadastro.php.
  2. ServidorO PHP entra em ação e executa o código, linha por linha.
  3. MySQLSe precisar, ele busca ou grava dados no banco.
  4. HTMLVolta só o HTML pronto. O código PHP nunca sai do servidor.

Desenvolver competências para projetar e implementar aplicações web dinâmicas utilizando PHP, banco de dados MySQL e recursos de integração com serviços externos, aplicando boas práticas de programação e desenvolvimento orientado a objetos.

  • Utilizar Web Services para consumo e integração de informações em aplicações web.
