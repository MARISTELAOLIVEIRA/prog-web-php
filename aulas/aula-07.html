Fac Senac DF Aula 7 Situação-problema SA 1

Recebendo dados do usuário

Atividade do dia: Cadastro de clientes, versão 1.

Objetivo do dia

Os estudantes constroem o formulário de cadastro de clientes da loja, integrando HTML e PHP: campos, atributos name, método de envio e a primeira resposta do servidor.

Competência

Integrar páginas HTML a scripts PHP do lado do servidor.

Situação de aprendizagem

Situação de Aprendizagem 1: Desenvolvimento da lógica de negócio de um sistema web.

P1 · problematização

O problema do dia

A loja recebe os pedidos pelo WhatsApp e perde clientes no meio das conversas. Como um formulário pode resolver isso?

C1 · conceitos

O que a gente vai usar

  • O formulário HTML: form, label, input, select, textarea e button
  • Atributos action, method e name: é pelo name que o PHP encontra o valor
  • Tipos de campo do HTML5: email, tel, number e date
  • Integração entre HTML e PHP no mesmo arquivo
  • Acessibilidade: label ligado ao campo pelo for e pelo id
T1 · mão na massa

Passo a passo do laboratório

A professora demonstra cada passo, e você faz junto no seu computador.

  1. Formulário de cadastro de clientes com nome, e-mail e telefone
  2. Recebimento dos dados no PHP e mensagem de boas-vindas
  3. Teste do campo sem name: o dado some sem dar erro
  4. Commit da versão 1 do cadastro
G1 · desafio gamificado

Desafio gamificado

  • Formulário-relâmpago: cada dupla sorteia um negócio (pet shop, oficina, doceria) e monta o formulário de cadastro em 15 minutos. A turma vota no mais claro e acessível
  • Quiz do módulo 5 do Curso Básico de PHP
F1 · fechamento

Fechamento

  • Do formulário ao servidor: o que viaja quando o botão é clicado
CU1 · estudo de caso

A doceria que vendia pelo WhatsApp

Caso fictício, criado para a aula.

Uma doceria do bairro recebia todas as encomendas por mensagem. Pedidos se perdiam no meio das conversas, faltavam o telefone e a data de entrega, e a dona passava a noite copiando tudo para um caderno. Ela pediu um formulário de encomendas no site.

Para discutir em grupo

Que campos o formulário precisa ter? Quais são obrigatórios? Que tipo de campo do HTML5 ajuda o cliente a digitar certo? O que o PHP deve fazer quando o pedido chega?
