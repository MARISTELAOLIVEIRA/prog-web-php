Fac Senac DF Aula 2 Laboratório de práticas SA 1

Preparando o ambiente PHP

Atividade do dia: Ambiente pronto.

Objetivo do dia

Configuração do ambiente de desenvolvimento web no laboratório: servidor Apache com PHP (XAMPP), servidor embutido do PHP (Lab-PHP), editor VS Code e versionamento com GitHub. Os estudantes escrevem e executam o primeiro script e entendem a estrutura de um projeto.

Competência

Preparar e utilizar o ambiente de desenvolvimento de aplicações web.

Situação de aprendizagem

Situação de Aprendizagem 1: Desenvolvimento da lógica de negócio de um sistema web.

P1 · problematização

O problema do dia

Por que o arquivo .php aberto direto no navegador mostra o código, e não a página?

C1 · conceitos

O que a gente vai usar

  • Servidor web Apache e o interpretador PHP: quem recebe o pedido e quem executa o código
  • Pasta htdocs do XAMPP e o endereço localhost
  • Servidor embutido do PHP: php -S localhost:8000
  • Estrutura de um projeto: pastas, arquivos .php, README e .gitignore
  • Sintaxe básica: as tags <?php e ?>, o echo e os comentários
T1 · mão na massa

Passo a passo do laboratório

A professora demonstra cada passo, e você faz junto no seu computador.

  1. Instalar e ligar o Apache no painel do XAMPP
  2. Abrir a pasta do projeto no VS Code e ligar o servidor embutido pelo terminal
  3. Criar o ola.php com echo, a data de hoje e um comentário
  4. Ver o código-fonte no navegador e conferir que o PHP não aparece
  5. Criar o repositório da disciplina no GitHub e fazer o primeiro commit
G1 · desafio gamificado

Desafio gamificado

  • Caça ao erro: três scripts com defeito (tag não fechada, ponto e vírgula faltando, arquivo fora da pasta do servidor). Quem consertar primeiro ganha XP
  • Quiz do módulo 1 do Curso Básico de PHP (nota mínima de 60%)
F1 · fechamento

Fechamento

  • Checklist do ambiente: o que precisa estar funcionando para a próxima aula
CU1 · estudo de caso

Na minha máquina funciona

Caso fictício, criado para a aula.

Um estagiário recebeu a tarefa de mostrar ao cliente a página de promoções de uma loja. Abriu o arquivo promocoes.php com dois cliques e, na frente do cliente, apareceu o código inteiro, com o nome do banco e a senha. No computador do colega, que usava o XAMPP, a página aparecia certinha.

Para discutir em grupo

O que faltou no computador do estagiário? Por que o código ficou exposto? Que cuidados a equipe deve ter antes de mostrar um sistema ao cliente?
